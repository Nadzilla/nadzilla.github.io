Provenir · Performance

Decision Trees Now Load Seven Times Faster After Rendering Rewrite

Trees with thousands of nodes stay lag free to view, scroll, and edit

By Mohammed AlnadiSenior Full Stack Engineer

Seven years into shipping features end to end across five SaaS products in financial decisioning, I work from PostgreSQL and Spring Boot REST APIs through the Angular and Vue interfaces customers use daily.

At Provenir, where I have been a senior software engineer since January 2020, I rewrote the Decision Tree rendering path. Trees with thousands of nodes load 7× faster and stay lag free to view, scroll, and edit.

I use Claude Code daily and helped set up my team’s agentic workflows, from shared project rules to agents running multi-step refactors and tests.
